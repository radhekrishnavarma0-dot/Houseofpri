# House of Pri website

Single-file website. All editable text is in the `CONTENT` block at the top of the `<script>` in `index.html`.

## Publish on GitHub Pages (free)
1. Create a free account at github.com and click New repository (name e.g. `house-of-pri`, Public).
2. Upload `index.html`, `robots.txt` and `README.md` (Add file > Upload files) and Commit.
3. Go to Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, Save.
4. After a minute the site is live at https://YOUR-USERNAME.github.io/house-of-pri/

## Before going live
- Set `email` in CONTENT (the contact form does not work without it).
- Replace every `[OWNER TO CONFIRM]` text (founder bio, prices, privacy, terms).
- Have Privacy Policy and Terms reviewed by a professional.
- Never put passwords or secret keys in this repo.

## To edit later
Open `index.html` on GitHub, click the pencil icon, change text inside the quotes, Commit.
